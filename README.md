# Birthday Surprise App 💜

A romantic interactive birthday microsite built with Streamlit, in a
lavender · purple · white theme with floating pink and purple hearts.

## Editing the final letter
Open `app.py` and find the `FINAL_LETTER` block near the top of the file
(just under the imports). Replace the placeholder text between the triple
quotes with your own words — nothing else needs to change.

## Run locally
```bash
pip install -r requirements.txt
streamlit run app.py
```

## Deploy on Streamlit Community Cloud
1. Create a GitHub repository.
2. Upload `app.py`, `requirements.txt`, and the entire `assets` folder
   (keep the folder structure exactly as it is — the images must stay
   inside an `assets` folder next to `app.py`).
3. Open Streamlit Community Cloud.
4. Select your GitHub repository.
5. Set the main file to `app.py`.
6. Deploy.

The four uploaded photos are already included in `assets/`.
